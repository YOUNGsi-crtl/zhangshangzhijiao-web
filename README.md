# 掌上智康微信小程序 MVP

这是可直接导入微信开发者工具的原生微信小程序第一版。

## 已实现
- 首页、训练、课程详情、AI校准、AI训练、训练报告、训练历史、挑战、我的、隐私设置
- 原生微信小程序 WXML/WXSS/JS
- 摄像头页面
- Mock AI 动捕评分与错误反馈
- 训练记录本地存储
- 一键清除训练数据
- 会员/AI能力的前端扩展位置

## 导入
1. 打开微信开发者工具
2. 导入项目目录
3. AppID 可先使用测试号/游客模式
4. 编译运行

## 重要说明
当前版本的 AI 动捕是 Mock 引擎：页面会模拟关键点、评分和纠正提示，便于先验证产品交互。
真正的 33 关键点人体姿态识别、DTW 动作比对、运动学规则库和端侧推理，需要在后续将 utils/mockAI.js 替换为真实模型能力，并按目标运行环境选择微信端可用的推理方案或后端/插件接口。
